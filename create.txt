================================================================================
                                 ABSTRACT
================================================================================
MultiModAI is a comprehensive, hybrid Full-Stack Single-Page Application (SPA) 
designed to democratize access to advanced Artificial Intelligence across critical 
everyday domains: Healthcare, Agriculture, Education, and Personal Finance. By 
seamlessly integrating Google Gemini 2.5 Flash for multimodal reasoning (text and 
image analysis) and Roboflow for specialized computer vision object detection, 
the platform delivers real-time, actionable insights and expert-level 
recommendations directly to users. 

The system is architected on a robust Python Flask backend and a modern, 
responsive React + Vite frontend, ensuring both high performance and scalability. 
MultiModAI effectively bridges the significant gap between complex, siloed AI 
technologies and everyday user needs. It empowers individuals by offering 
accessible, high-tech features such as automated disease detection from medical 
scans, precision crop health analysis for farmers, personalized career roadmaps 
for students, and intelligent financial auditing, fostering better decision-making 
through accessible technology.

================================================================================
                            CHAPTER 1 - INTRODUCTION
================================================================================

1.1 Problem Statement
---------------------
Access to specialized expert knowledge in healthcare, agriculture, and financial 
planning is often expensive, time-consuming, or geographically limited. 
Furthermore, while powerful AI models exist, they are frequently siloed, require 
significant technical expertise, or are inaccessible to non-technical users.

- Healthcare: Patients often wait days for radiological reports, and diagnostic 
  facilities are limited in rural areas.
- Agriculture: Farmers lack immediate access to agronomists for crop disease 
  identification, leading to crop losses.
- Education: Personalized career roadmaps and guided mentorship usually require 
  expensive human consultants.
- Finance: Custom financial auditing, expense classification, and medical bill 
  auditing against policy details are complex and manual.

The core problem MultiModAI solves is the latency and accessibility of expert 
insights. By combining the specific visual recognition capabilities of Roboflow 
with the reasoning power of broad knowledge experts like Gemini, the platform 
delivers immediate, high-quality analysis and advice.

1.2 Existing System
-------------------
Existing systems in these domains are typically standalone applications that do 
not share data or interface architectures. A user must use one app for medical 
imaging, another for financial planning, and a separate service for educational 
mentoring. 

Furthermore, existing AI tools suffer from several limitations:
1. Single-Model Reliance: Most tools rely on a single model (either vision or 
   text) which reduces validation accuracy.
2. High Response Latency: Processing massive pipelines sequentially can cause 
   system timeouts.
3. Lack of Accessibility: Tools rarely include speech synthesis (Text-to-Speech) 
   and local language support (e.g., Hindi/Telugu) simultaneously.
4. Minimal Admin Control: No operations dashboard to track API costs, system load, 
   active processes, and error statuses.

1.3 Proposed System
-------------------
MultiModAI resolves these issues by consolidating these expert systems into a 
single, user-friendly web application with a unified Command Center. The 
proposed system introduces:
- Unified Command Dashboard: A sleek glassmorphism dashboard built with React 
  and Tailwind CSS, featuring a dynamic digital twin node SVG diagram showing real-time 
  data flow streams from the core to specialized modules.
- Multi-Model Hybrid Verification: Combines Roboflow (vision model), Llama 3.1 
  (Cerebras Cloud for speed/specialized assessment), and Google Gemini 2.5 Flash 
  (synthesis and reasoning) to cross-verify diagnostic outputs.
- Localized RAG (Retrieval-Augmented Generation): Integrates PDF ingestion to 
  extract relevant context (e.g., medical reference guides, insurance policy 
  clauses) to ground the generative suggestions.
- Real-Time Operations Monitoring: Includes an admin dashboard console tracking 
  model accuracies, system health circles, audit logs, and live request streams.
- Multilingual and Voice Support: Built-in translation context supporting English, 
  Hindi, and Telugu, integrated with Google Text-to-Speech (gTTS) to vocalize 
  diagnoses.

1.4 Scope
---------
The scope of MultiModAI includes:
1. Authentication: Secure JWT-based registration and login with encrypted passwords.
2. Medical Diagnosis: Uploading MRI, X-ray, or skin scans to detect fractures, 
   brain tumors, eye diseases, and skin conditions, coupled with conversational 
   clinical advice.
3. Agriculture Agri-Vision: Crop leaf analysis for disease detection and context-aware 
   crop recommendation mapping using interactive geographic charts.
4. EduMentor Workspace: Career roadmap plotting, text simplifiers, and automatic 
   quiz generation.
5. Smart Billing: Hospital bill estimation and insurance coverage auditing.
6. System Administration: Real-time service checks, API cost telemetry, and action tools 
   to trigger diagnostics or restart servers.

3.1 Features
------------
The application features a comprehensive command console dashboard and five distinct 
functional hubs:

1. Unified Dashboard Command Center
   - Operations status indicator: Pulse animations representing live server state.
   - Five interactive KPI cards: Total interactions, Active Models, AI Confidence, 
     Reports Generated, and Scan Images.
   - Interactive Digital Twin SVG Map: Custom coordinate layout mapping nodes. 
     Displays animated flow arrows connecting "Core AI" to "Specialized Hubs" on hover.
   - Trend lines: Interactive Recharts showing weekly request volume and accuracy forecasts.

2. Medical AI Hub (🩺)
   - Visual Scan Analyzer: Detects brain tumors, lung conditions, fractures, eye 
     pathologies, skin diseases, and gastrointestinal anomalies.
   - Roboflow Object Detection: Displays matching bounding boxes and confidence rates.
   - Three-Model Hybrid Synthesis: Combines Roboflow's bounding coordinates with 
     Llama 3.1's technical assessment and Gemini's conversational layout.
   - General Consultation Chat: Answers generic medical queries, referencing a 
     pre-loaded reference medical handbook via a localized RAG system.
   - Voice Feedback: Integrated Google Text-to-Speech synthesis with options to 
     play, pause, or download diagnostic reports in MP3 format.

3. Agriculture AI Hub (🌾)
   - Agri-Vision Crop Disease Upload: Uploads plant leaf photos to identify infections 
     (e.g., Late Blight, Rust, Leaf Spot) and outputs organic treatment advice.
   - Smart Crop Recommender: Evaluates location, season, soil pH, and watering schedules. 
     Returns a structured Markdown table mapping recommended crops, estimated costs, 
     potential profit, and crop risk levels.
   - Geographic Context Mapping: Connects location parameters with an interactive Leaflet 
     JS Map displaying agricultural markers in relevant regions.

4. EduMentor Student AI Hub (🎓)
   - Text Simplifier: Automatically rewrites dense research literature and study sheets 
     into simplified concepts based on age group.
   - MCQ Quiz Generator: Evaluates text content and outputs five interactive, multiple-choice 
     questions with scoring grids.
   - Study Planner: Generates daily checklists and goals based on days-to-exam and topic.

5. Finance AI Hub (💰)
   - Spending Analyzer: Generates interactive spending breakdown charts using Recharts 
     based on uploaded CSV transaction files.
   - Smart Insurance Surveyor & Bill Auditor: Parses policy details (PDF files) and 
     validates hospital bill items. Checks Room Rent Caps, Copayments, and Exclusions, 
     outputting estimated bills, coverage totals, and patient pay.

6. Security & Admin Operations Control Panel (🛡️)
   - Real-time gauge: Overall platform health index circle (96% Score).
   - API Cost and Telemetry meters: Tracks active requests and counts.
   - Audit event logger table: Captures user registrations, administrative logins, and 
     model changes.
   - Action Hub buttons: Diagnostics triggers, model resets, user permissions controls.

3.3 Environmental Setup
-----------------------
Follow these steps to establish the developer workspace locally:

A. Python Backend Environment Setup
1. Open PowerShell / Command Prompt and clone the repository.
2. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```
3. Initialize the Python virtual environment:
   ```bash
   python -m venv .venv
   ```
4. Activate the virtual environment:
   - On Windows (PowerShell):
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
   - On Linux/macOS:
     ```bash
     source .venv/bin/activate
     ```
5. Install backend package dependencies:
   ```bash
   pip install -r requirements.txt
   ```
6. Set up the local `.env` environment variables file inside the `backend/` directory:
   ```env
   GEMINI_API_KEY=your_google_gemini_api_key
   ROBOFLOW_API_KEY=your_roboflow_private_api_key
   MONGO_URI=mongodb://localhost:27017/ai_platform
   JWT_SECRET_KEY=highly_secure_random_string_key
   CEREBRAS_API_KEY=your_cerebras_llama_api_key
   ```
7. Start the Flask developer server (binds on port 5000):
   ```bash
   python app.py
   ```

B. React Frontend Environment Setup
1. Open a second terminal window and navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```
2. Ingest required Node.js package dependencies:
   ```bash
   npm install
   ```
3. Start the Vite hot-reloading development server (binds on port 3000/3001):
   ```bash
   npm run dev
   ```

3.4 Implementation and Methodology Steps
----------------------------------------
The MultiModAI application utilizes a structured developer methodology:

1. Modular Routing (Blueprints): The core Flask web server (`app.py`) initializes 
   CORS, connects to MongoDB, and registers Blueprints. This splits routes 
   into dedicated context domains (`auth_routes.py`, `medical_routes.py`, etc.).
2. Database Schema Modeling: MongoDB acts as a flexible storage repository. 
   User records contain hashed string passwords. History documents store metadata 
   for every model query, which supports history review inside the React UI.
3. RAG Document Ingestion: The RAG engine initializes on application startup. 
   `medical_service.py` looks inside the `data/knowledge_base/` folder. It parses 
   PDF documents using `pypdf`, extracts page strings, and builds an index. 
   When queries match indexed terms, contextual excerpts are retrieved and injected 
   into Gemini's prompt space.
4. API Wrapper Engineering: We build wrapper services utilizing the new 
   `google-genai` SDK. This architecture specifies `gemini-2.5-flash` as the core 
   model and lists fallback identifiers (`gemini-2.5-flash-lite`, `gemini-2.0-flash`) 
   to handle network retry loops cleanly.
5. Unified Cross-Origin Config: To deploy on serverless routers (such as Vercel), 
   the project implements a root-level `vercel.json` routing configuration. All 
   frontend routes serve the built React bundle, and requests prefixed with 
   `/api/*` are redirected to the Python WSGI adapter in `app.py`.

5.1 Conclusion
--------------
MultiModAI succeeds in consolidating specialized domain intelligence into a unified, 
data-dense command dashboard interface. By combining visual object recognition with 
multimodal reasoning, the platform reduces dependency on human consultants for 
preliminary assessments. Security controls like JWT validation and Bcrypt password 
hashing, along with real-time admin metrics, ensure that the system functions as a 
production-ready dashboard platform. The integration of local language context and 
TTS audio conversion provides accessibility to a diverse audience.

5.2 Future Enhancements
-----------------------
Future updates plan to expand the system's capabilities through the following steps:

```python
import sys
import os

# Fix Vercel Python path: CWD is project root (/var/task),
# but all modules (config, extensions, routes, services) live in backend/.
# This must be FIRST before any local imports.
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from flask import Flask, jsonify, request, send_from_directory
from flask_cors import CORS

from config import config
from extensions import mongo, bcrypt, jwt


# Path to the built React frontend
BASE_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
FRONTEND_DIST = os.path.join(BASE_DIR, 'frontend', 'dist')


def create_app():
    app = Flask(__name__, static_folder=None)

    # CORS Configuration
    CORS(app, resources={r"/api/*": {"origins": "*"}}, supports_credentials=True)

    # Config Ingestion
    app.config.from_object(config)
    app.config.setdefault('JWT_SECRET_KEY', config.JWT_SECRET_KEY)

    # Extensions Ingestion
    mongo.init_app(app)
    bcrypt.init_app(app)
    jwt.init_app(app)

    # Blueprints Registration
    from routes.auth_routes import auth_bp
    from routes.medical_routes import medical_bp
    from routes.student_routes import student_bp
    from routes.finance_routes import finance_bp
    from routes.agriculture_routes import agriculture_bp
    from routes.dashboard_routes import dashboard_bp
    from routes.settings_routes import settings_bp
    from routes.tts_routes import tts_bp
    from routes.billing_routes import billing_bp
    from routes.admin_routes import admin_bp

    app.register_blueprint(auth_bp,        url_prefix='/api/auth')
    app.register_blueprint(medical_bp,     url_prefix='/api/medical')
    app.register_blueprint(student_bp,     url_prefix='/api/student')
    app.register_blueprint(finance_bp,     url_prefix='/api/finance')
    app.register_blueprint(agriculture_bp, url_prefix='/api/agriculture')
    app.register_blueprint(dashboard_bp,   url_prefix='/api/dashboard')
    app.register_blueprint(settings_bp,    url_prefix='/api/settings')
    app.register_blueprint(tts_bp,         url_prefix='/api/tts')
    app.register_blueprint(billing_bp,     url_prefix='/api/billing')
    app.register_blueprint(admin_bp,       url_prefix='/api/admin')

    # Health check
    @app.route('/api/health', methods=['GET'])
    def health_check():
        mongo_uri = app.config.get('MONGO_URI', '')
        is_localhost = 'localhost' in mongo_uri or '127.0.0.1' in mongo_uri
        db_status = "unknown"
        db_error = None
        try:
            mongo.db.command('ping')
            db_status = "connected"
        except Exception as e:
            db_status = "error"
            db_error = str(e)
        return jsonify({
            "status": "healthy",
            "service": "MultiModAI Backend",
            "db_status": db_status,
            "db_type": "localhost" if is_localhost else "atlas",
            "db_error": db_error,
            "mongo_uri_set": bool(mongo_uri),
        }), 200

    # Serve React SPA Catch-all
    @app.route('/', defaults={'path': ''})
    @app.route('/<path:path>')
    def serve_react(path):
        if path and os.path.isfile(os.path.join(FRONTEND_DIST, path)):
            return send_from_directory(FRONTEND_DIST, path)
        return send_from_directory(FRONTEND_DIST, 'index.html')

    return app

app = create_app()

if __name__ == '__main__':
    app.run(debug=True, host='0.0.0.0', port=5000)
```

class MedicalService:
    def __init__(self):
        self.api_key = os.getenv('GEMINI_API_KEY')
        if self.api_key:
            self.client = genai.Client(api_key=self.api_key)
            self.model_id = 'gemini-2.5-flash' 
        else:
            self.client = None
            
        self.knowledge_base_path = None
        self.knowledge_index = [] 
        self._load_knowledge_base()

    def _load_knowledge_base(self):
        kb_dir = os.path.join(os.getcwd(), 'data', 'knowledge_base')
        if os.path.exists(kb_dir):
            files = [f for f in os.listdir(kb_dir) if f.lower().endswith('.pdf')]
            if files:
                self.knowledge_base_path = os.path.join(kb_dir, files[0])
                try:
                    reader = PdfReader(self.knowledge_base_path)
                    for i, page in enumerate(reader.pages):
                        text = page.extract_text()
                        if text:
                            self.knowledge_index.append({"page": i+1, "text": text})
                except Exception as e:
                    print(f"Failed to index PDF: {e}")

    def _retrieve_context(self, query):
        if not self.knowledge_index or not query:
            return ""
        query_words = set(query.lower().split())
        scored_pages = []
        for entry in self.knowledge_index:
            score = sum(1 for word in query_words if word in entry['text'].lower())
            if score > 0: scored_pages.append((score, entry))
        scored_pages.sort(key=lambda x: x[0], reverse=True)
        top_results = scored_pages[:3]
        return "\n\n".join([f"--- Page {x[1]['page']} ---\n{x[1]['text']}" for x in top_results])

    def get_ai_guidance(self, condition, confidence, language='en', image_path=None, user_notes=''):
        """
        Implementing 3-Model Hybrid (Roboflow + Llama + Gemini) Cross-Verification.
        """
        if not self.client: return "AI Guidance unavailable."

        rag_context = self._retrieve_context(f"{condition} {user_notes}") if not image_path else ""

        # Llama Assessment Prompt
        llama_prompt = f"Analyze this Medical Finding:\n- Condition: {condition}\n- Confidence: {confidence}%\n- Patient Notes: {user_notes}"
        llama_analysis = cerebras_service.generate_content(llama_prompt, "You are a senior medical board examiner.")

        # Gemini Visual Verification Prompt
        gemini_vision_prompt = f"Analyze this scan. Context suggests: {condition} ({confidence}% confidence). Does image confirm?"
        contents = [gemini_vision_prompt]
        if image_path:
            img = PIL.Image.open(image_path)
            contents.append(img)
        gemini_vision_result = generate_content_with_retry(self.client, self.model_id, contents).text

        # Final Master Synthesis
        final_synthesis_prompt = f"""
        You are the Master Medical Architect. Cross-verify:
        1. Vision Engine Result: {condition} ({confidence}%)
        2. Llama 3.1 Analysis: {llama_analysis}
        3. Gemini Vision Evidence: {gemini_vision_result}
        
        Combine these into a single high-reliability report in {language} language.
        Start with: "This output is cross-verified by 3 AI models (Roboflow, Llama 3.1, and Gemini) for maximum reliability."
        """
        final_report = generate_content_with_retry(self.client, self.model_id, final_synthesis_prompt)

class BillingService:

    def analyze_billing_scenario(self, hospital_name, city, room_type, admission_reason, duration='3', age='30', treatment_type='Medical Management', tier='Tier-1', gender='Male', icu_days='0', surgery_complexity='Medium', emergency='false', implant='false', network_hospital='true', policy_path=None):
        if not self.client:
            return {"error": "AI Service Unavailable"}

        scenario = f"""
        **Hospitalization Scenario:**
        - Hospital: {hospital_name} | City: {city}
        - Selected Room: {room_type} | Tier: {tier}
        - Reason: {admission_reason} | Duration: {duration} Days (ICU: {icu_days} Days)
        - Patient: {age} Years | {gender}
        """

        You are an Expert Medical Insurance Surveyor and Hospital Bill Auditor in India.
